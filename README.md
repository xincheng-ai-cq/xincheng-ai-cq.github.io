# 鑫诚则灵个人工作室主页 · 1.0

重庆鑫诚则灵个人工作室，聚焦成果资产管理与价值表达。

本仓库保存主页的 HTML、CSS、JavaScript、品牌图形和网站展示资源。包含六项案例、34 张展示页和一个动画视频。

## 浏览与维护

GitHub Pages 使用 `main` 分支的仓库根目录发布；`.nojekyll` 使静态资源按原样提供。

- `index.html`：页面正文与结构。
- `styles.css`：样式与响应式布局。
- `app.js`：导航、案例筛选、多页作品浏览、动画和需求文件下载。
- `assets/`：网站展示图片、标志和视频。

保留上述目录关系即可本地浏览。更新文件并推送到 `main` 后，GitHub Pages 会重新发布。

1.0 暂不公开联系方式。项目需求表仅将填写内容下载到访客自己的设备，不向工作室或服务器发送内容。

## 作品与资料

仅网站运行文件进入本仓库；客户原稿、可编辑交付原件、项目台账、内部过程记录和本机管理文件保留在本地归档。

案例展示为工作室的服务成果介绍。客户标志、作品画面及相关资料的权利归各自权利人；仓库公开不代表授予其再使用许可。
